# Contributing to IngestX

First off, thank you for considering contributing to IngestX! ❤️

Whether it's fixing a bug, improving documentation, adding a new validator, or suggesting a feature, every contribution is appreciated.

## Getting Started

1. Fork the repository.
2. Clone your fork.
3. Install dependencies:

```bash
yarn install
```

4. Start the development environment:

```bash
yarn run dev
```

## Making Changes

- Create a new branch for your changes.
- Keep pull requests focused on a single feature or fix.
- Follow the existing code style.
- Add or update tests whenever applicable.
- Update documentation if your change affects the public API.

## Pull Requests

Before opening a PR, make sure:

- All tests pass.
- Your code is formatted.
- Your PR includes a clear description of the changes.
- Related issues are referenced (if any).

## Reporting Issues

When opening an issue, please include:

- A clear description of the problem.
- Steps to reproduce (if applicable).
- Expected vs actual behavior.
- Environment details (browser, Node version, etc.).

## Questions

If you're unsure where to start, look for issues labeled **good first issue** or **help wanted**.

Thanks for helping make IngestX better!
